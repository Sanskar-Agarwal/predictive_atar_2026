Class Marks

The individual subject reports include class marks for each subject. Note that class marks are based on marked work
completed in class and/or for homework. These marks represent the ongoing process of formative assessment, and
are distinct from the summative nature of School examinations. Class marks are generated by individual masters and
are not moderated between classes. They should therefore be interpreted only within the context of the work
undertaken by that individual class. To assist with that interpretation class marks are represented graphically, in a

manner explained by the following diagram:

Class Descriptions

To assist with your interpretation of class marks within their appropriate context, a description of the class your son
is in has been included with his subject report.

Streamed class means that boys have been arranged into classes according to past examination performance.
Parallel class means that classes have not been arranged by past examination performance, and there may be
several similar classes.

Single class means that class is the only one in a subject for a cohort.
